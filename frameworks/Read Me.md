## How to Choose a Framework

| Your situation | Start with |
|---|---|
| "We haven't started our AI journey" | Readiness Assessment → Transformation Model |
| "We have pilots but can't scale" | Operating Model Canvas → Value Realization |
| "Leadership needs a business case" | Value Realization Framework → Industry Playbooks |
| "We need governance before deploying" | Governance Frameworks → Scenario library |
