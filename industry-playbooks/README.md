# Industry Playbooks

The Shinnawy AI Transformation Model™ is **industry-agnostic**.

These playbooks demonstrate how the methodology adapts to specific sector contexts — they are applications of the framework, not replacements for it.

## How to Contribute an Industry Playbook

If you work in a sector not yet covered and want to contribute a playbook:

1. Fork the repository
2. Create a folder under `industry-playbooks/[your-industry]/`
3. Follow the template structure in any existing playbook
4. Submit a pull request

Playbooks must reference at least two phases of the Shinnawy AI Transformation Model™.
